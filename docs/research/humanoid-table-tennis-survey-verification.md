# Verification pass on berkeley-us.md, china-games.md, code-sweep.md

Method: every GitHub repo URL checked via `gh api repos/<owner>/<repo>` (falls back through
redirects automatically) plus a raw README fetch for the repos central to the three notes'
claims; org-level repo listings pulled via `gh api orgs/<org>/repos` (or `users/<org>/repos`
where the account turned out to be a user, not an org); every arXiv/project/news URL below was
opened with WebFetch. Checked 2026-08-27, same day as (or one day after) the source notes.

Overall verdict: the three research files are **very accurate**. Every repo exists, every
license/date/star claim checked matched exactly, and every "no code released" claim held up.
I found one real error (a license mischaracterization) and a handful of minor
one-off discrepancies (repo counts, an unsupported citation), detailed below and flagged inline
in the tables.
